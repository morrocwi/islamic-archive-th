# แผนที่เอกสาร / Document Map

สถานะการรวบรวมกฎหมายลำดับรองและเอกสารปฏิบัติงาน ที่เกี่ยวกับการบริหารองค์กรศาสนาอิสลาม/มัสยิดในประเทศไทย
ใช้ไฟล์นี้เป็น backlog — เมื่อหาต้นฉบับ (PDF/URL) ของรายการใดยืนยันได้แล้ว ให้ ingest ตาม `docs/PROCESS.md`
แล้วอัปเดตคอลัมน์ **สถานะ** พร้อมใส่ `id` ของเรคคอร์ดที่ได้

> **หมายเหตุความน่าเชื่อถือ**: ชื่อ/เลขฉบับ/ปี พ.ศ. ของรายการที่ยังไม่ ingest ด้านล่างส่วนใหญ่มาจากคำตอบของ
> AI ตัวอื่น (secondhand, ยังไม่ตรวจกับต้นฉบับ) — ห้ามถือเป็นข้อเท็จจริงจนกว่าจะเจอเอกสารต้นฉบับจริงมายืนยัน
> ตามหลัก readout-not-truth (ดู `README.md`)

## ขั้นตอนถัดไป

ผู้ใช้จะทยอยหาลิงก์/ไฟล์ต้นฉบับของแต่ละรายการมาให้ทีละอย่าง — เมื่อได้รับแล้ว ให้ทำตาม `docs/PROCESS.md`
(ดาวน์โหลด PDF → สกัดภาษาไทย → แปล → ตรวจสอบ → validate → commit) แล้วขยับสถานะในตารางนี้เป็น ✅ ingested
พร้อม `id` ของเรคคอร์ด — Tier 2-4 (กฎกระทรวง/ระเบียบ กอท./พระราชกฤษฎีกา) ยังรอต้นฉบับทั้งหมด
